# Todo API

API REST construida con Spring Boot 3 y Java 17.

## Stack
- Java 17
- Spring Boot 4.0.3
- Maven

## Endpoints
| Método | Ruta    | Descripción              |
|--------|---------|--------------------------|
| GET    | /hello  | Saludo de prueba         |
| GET    | /info   | Información de la API    |

## Cómo ejecutar
```bash
./mvnw spring-boot:run
```
La API arranca en http://localhost:8080
